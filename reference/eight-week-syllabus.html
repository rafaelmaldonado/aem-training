De authoring a desarrollo AEM.

An eight-week path for six remote developers with frontend and authoring experience, building AEM technical foundations from the ground up.

  • AEM Sites tradicional
  • 30 min en línea
  • 60–120 min de práctica
Formato diario: 3 min de recuperación, 2 min de objetivo, 12 min de slides, 8 min de demo, 3 min para explicar el ejercicio y 2 min de cierre. Después: 60–120 min de práctica asíncrona.

Course objective: Enable frontend-oriented developers to maintain, extend, test, deploy and troubleshoot traditional AEM Sites solutions on AEM as a Cloud Service.

La práctica es el núcleo. El tiempo restante de la ventana disponible de 2–4 horas se usa en proyecto integrador, lectura oficial o PR review, sin extender la sesión en línea.

Proyecto del curso: mantenimiento y extensión del repositorio oficial WKND mediante el escenario Weekend Guides. Abrir el backlog de 48 historias →

Course outcomes

  • Explain how content and code travel from Author to the browser.
  • Read an AEM project structure and locate a change in the correct module.
  • Modify authorable components with HTL, dialogs, client libraries and Sling Models.
  • Build, test, review and deploy changes compatible with AEM as a Cloud Service.
  • Troubleshoot foundational AEM, Dispatcher, caching and pipeline issues.
  • Demonstrate individual proficiency through working artifacts and technical explanation.

Proyecto transversal

Usar una copia sanitizada del proyecto real. Si no existe, partir de WKND y tratarlo como una base heredada. El backlog debe contener cambios pequeños: componente proxy, diálogo/política, Sling Model, configuración, caché, pipeline, permisos y un defecto ambiguo. No agregar SPA, Forms, Commerce, Headless o EDS al núcleo.

Presentaciones del equipo

Los viernes, una persona presenta durante 8 minutos y responde preguntas durante 7. Explica algo ya aplicado: una demo, una decisión y un error frecuente. Las presentaciones refuerzan el aprendizaje; no sustituyen la clase ni la evidencia individual.
