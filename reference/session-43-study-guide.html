El caso

En una rama desechable msm-43-lab bajo una página que no sea Live Copy, crea source/guide y source/contact. En WKND local podría ser /content/wknd/language-masters/en/msm-43-lab si el template lo permite; no ejecutes Rollout desde sus ancestros. El primero tiene dos Text distintos y un Button que enlaza, mediante el picker, a source/contact. Una Live Copy profunda llamada canada crea las contrapartes canada/guide y canada/contact. Ambas ramas permanecen en inglés para aislar el comportamiento de MSM. Estas rutas son ilustrativas; no afirman que las páginas ya existan en tu SDK.

Configuración y referencias

Standard rollout config usa el trigger On Rollout e incluye contentUpdate, contentCopy, contentDelete, referencesUpdate, productUpdate y orderChildren. Rollout desde una fuente con blueprint configuration empuja; Synchronize desde la Live Copy trae cambios y ejecuta configuraciones con ese trigger. Guardar en el origen no dispara automáticamente esta configuración. La configuración efectiva puede venir de la Live Copy, la página blueprint, el padre o el valor del sistema. Adobe: configurar la sincronización · Adobe: crear y sincronizar Live Copies.

referencesUpdate intenta cambiar una referencia que apunta dentro del árbol fuente hacia el recurso relacionado en la Live Copy; deja intactas las referencias externas al árbol. Si el enlace permanece en la fuente, comprueba el valor guardado, la contraparte, la configuración efectiva y si existe una Live Copy anidada. Adobe documenta una opción específica para actualizar referencias en copias anidadas. Adobe: referencias en Live Copies anidadas.

Práctica local en Author SDK

Prepara antes de clase: un sitio local y template que permitan Text y Button editables; permisos para crear páginas y Live Copies. No se necesita Java ni una acción de rollout personalizada.

  1. Bajo una página de práctica, crea msm-43-lab/source/guide y msm-43-lab/source/contact. En guide coloca dos Text: Shared heading v1 y Shared offer v1. Añade un Button Contact y selecciona source/contact con el picker.
  2. En Sites usa Create → Live Copy con source como origen y msm-43-lab como padre destino. Nombra la copia canada, incluye descendientes y selecciona Standard rollout config si el asistente la solicita. Comprueba las dos páginas hijas.
  3. En Properties → Live Copy de canada/guide, anota fuente, relación y configuración efectiva. Antes de editar, comprueba los valores y el destino del Button; puede estar ya localizado desde la creación.
  4. En canada/guide, cancela herencia sólo del segundo Text y cambia su valor a Canada local offer. El encabezado y el Button siguen heredando.
  5. En source/guide, cambia los Text a Shared heading v2 y Shared offer v2. Predice el resultado. En canada/guide usa Synchronize → Page Only; espera a que termine y comprueba los tres valores, incluido el path del Button.
  6. Registra primero la oferta canadiense. Reactiva herencia en el segundo Text y después solicita Synchronize por separado. Comprueba Shared offer v2. Reactivar la herencia no actualiza automáticamente el valor. Adobe: herencia de componentes.

Evidencia: ruta fuente y destino, configuración efectiva, estado de herencia de cada Text, valores tras sincronizar y destino real del Button. La tabla describe resultados esperados; este repositorio no contiene una ejecución registrada en AEM. Para el detalle y la matriz de momentos consulta la guía Markdown completa.

No uses Reset para una sola referencia: elimina cancelaciones y devuelve la página al estado fuente. Detach elimina permanentemente la relación. Ninguno es necesario para esta práctica. Adobe: Reset y Detach.

Localización: tres responsabilidades

ConceptoFunciónEvidencia
Live CopyReutiliza contenido con relación MSM y excepciones.Properties → Live Copy, herencia y configuración.
Language CopyOrganiza una rama bajo raíz de idioma.en, fr y References → Language Copies.
TraducciónGenera y mantiene contenido en otra lengua.Proyecto y estado de traducción; texto resultante.

MSM no traduce inglés a francés. Adobe recomienda usarlo dentro de un idioma, por ejemplo origen inglés hacia mercados en inglés, y origen francés hacia mercados en francés. Adobe: MSM y traducción · Adobe: Language Copies.

Repaso con respuestas

  1. ¿Por qué guardar el origen no basta? Standard usa On Rollout; hay que solicitar Rollout o Synchronize según la relación disponible.
  2. ¿Qué valor sigue local? El segundo Text, cuya herencia se canceló.
  3. ¿La etiqueta Contact prueba el destino? No; inspecciona el path real.
  4. ¿Qué limita referencesUpdate? Árbol fuente, contraparte relacionada, configuración efectiva y exclusiones.
  5. ¿Reactivar herencia sincroniza automáticamente? No; son operaciones distintas.
  6. ¿Language Copy equivale a Live Copy? No necesariamente. La traducción también es un proceso distinto.

Limpieza: tras guardar evidencia, elimina sólo la rama de práctica msm-43-lab. No modifiques las Live Copies reales de WKND.
