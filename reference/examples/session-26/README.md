# Sesión 26 · Consultas locales

Sigue la [guía completa](../../session-26-study-guide.html#ejemplos-locales) para crear tags y cinco páginas en tu SDK. No depende de prácticas anteriores.

- `querybuilder.properties`: pegar en QueryBuilder Debugger local.
- `guides.sql2`: pegar como JCR-SQL2 en la herramienta de consultas local.

Cambia `/content/wknd/us/en` por tu raíz real si usas Archetype. Conserva la subruta `training-search`. Con la cuenta que preparó el ejemplo, ambas consultas seleccionan Forest y River; SQL2 necesita límite/offset en la herramienta o API para comparar también la ventana. Son ejemplos documentales, no consultas ejecutadas ni resultados medidos en tu SDK.
