Class 43 · Week 9 · October 14, 2026

Resolve an MSM localization case

Keep a Canadian offer local while a shared heading and an internal page link follow the source.

  • 30-minute technical session
  • 12 PNG slides · Spanish presenter notes
  • Guía completa en español
Author SDK case: create a disposable Live Copy under a practice branch. Inspect its effective rollout configuration, cancel one component's inheritance, synchronize, and verify the actual link destination. The outcomes below are predictions until tested in your SDK.

Slide deck

Present these editable web slides in the browser, download each PNG, or print this page to PDF. Expand the Spanish notes under each slide for facilitation and source links.

Notas para LLM · slide 01

Presentar tres decisiones: herencia y dueño local, configuración y referencias, y separación entre MSM y traducción. Retomar la sesión 21. Todos los paths son de una rama desechable del Author SDK.

Notas para LLM · slide 02

La oferta local es una excepción comercial, no una traducción. No cancelamos herencia en toda la página. El botón apunta desde el origen a otra página dentro del mismo árbol; su destino real es la tercera evidencia.

Notas para LLM · slide 03

La configuración combina trigger y acciones. Standard rollout config trae esas seis acciones y On Rollout. Synchronize desde la Live Copy también ejecuta configuraciones con ese trigger. Si no hay blueprint configuration, el botón Rollout puede no estar disponible en la fuente; usa Synchronize en el destino.

Fuente: Adobe · Creating and Synchronizing Live Copies.

Notas para LLM · slide 04

El ejercicio usa un Button y el picker de páginas para guardar una referencia interna; evita escribir una URL arbitraria. La acción busca referencias al árbol fuente y puede cambiarlas al recurso relacionado. Un enlace externo o sin contraparte no obtiene una traducción por magia. La comprobación es el path real del Button.

Notas para LLM · slide 05

Registrar configuración efectiva antes de operar. Su selección puede venir de la propia Live Copy, la fuente blueprint, el padre o el valor del sistema. El estado previo evita atribuir a la sincronización un enlace que ya se había localizado al crear la copia.

Notas para LLM · slide 06

Seleccionar el segundo Text en el editor de la Live Copy, cancelar herencia y cambiarlo. No cancelar en el contenedor ni en la página. El primer Text y el Button siguen sujetos a los cambios elegibles de MSM.

Notas para LLM · slide 07

En la fuente, cambiar encabezado y oferta. Pedir la predicción antes de pulsar Synchronize. Elegir sólo la página guide; contact ya existe. La tercera celda es una expectativa condicionada a que el enlace sea una referencia reconocida y a que referencesUpdate sea efectiva. Verificar el destino, no sólo el render.

Notas para LLM · slide 08

Adobe documenta que una Live Copy anidada puede conservar enlaces al blueprint si Update Reference across nested LiveCopies no está habilitado. No cambiar OSGi de entrada: verificar ruta, contraparte, herencia y configuración. El resultado de Author manda sobre una predicción del slide.

Notas para LLM · slide 09

Restaurar herencia no sincroniza automáticamente el componente. Ejecutar Synchronize por separado para mostrar el efecto. Reset de página elimina excepciones y devuelve la página al estado de fuente; Detach elimina la relación MSM. No se usan en esta práctica.

Notas para LLM · slide 10

El ejercicio mantiene el inglés en origen y destino. En producción, Adobe recomienda usar MSM dentro de un idioma: un master inglés hacia mercados en inglés y uno francés hacia mercados en francés. Una Language Copy es una rama con raíz de idioma; puede existir sin relación MSM. La traducción se gestiona con el proceso correspondiente. ReferenciasUpdate mapea recursos relacionados, no crea una traducción faltante.

Fuentes: Adobe · Preparing Content for Translation.

Notas para LLM · slide 11

Pedir al grupo que nombre la evidencia para cada decisión: relación, configuración y alcance; estado de herencia; destino real del enlace; valor local antes de reactivar; y rama de idioma. Estas cinco comprobaciones resumen el caso.

Notas para LLM · slide 12

Abrir preguntas. Si hace falta, volver al enlace real del Button o a la oferta local. Cerrar sin añadir contenido nuevo.
