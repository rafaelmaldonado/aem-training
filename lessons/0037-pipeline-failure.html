Read a pipeline failure

Find the first actionable error, inspect local coverage, and explain a compatible recovery.

  • 30-minute core · up to 60 minutes
  • 9 PNG slides · theoretical session
  • Guía completa en español
Session focus: the pipeline traces are illustrative examples. Cloud Manager access and deployment are not required. The JaCoCo report is an optional local instructor demonstration; there are no participant exercises.
