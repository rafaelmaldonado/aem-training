Class 33 · Week 7 · September 30, 2026

Diagnose the Dispatcher cache

Prove a miss, a hit and a fresh response after a controlled content update.

  • 30-minute core · up to 60 minutes
  • Local Dispatcher Tools demo
  • Guía completa en español
Session focus: compare the same GET, Host and path on Publish and Dispatcher before and after publication.

Topic summary

Dispatcher stores responses selected by /cache/rules. After a content update, /invalidate and .stat timestamps can make stored HTML stale; TTL may also expire it. /ignoreUrlParams determines whether a query parameter is ignored for Dispatcher caching. Prove each decision with the Dispatcher log and Publish requests.
